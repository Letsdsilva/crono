# PM Estudos — Cronograma & Corretor de Redação

Aplicativo web de estudos feito com HTML, CSS e JavaScript puros (Tailwind via CDN).

## Arquivos
- `index.html` — estrutura da página (este nome é obrigatório para o GitHub Pages).
- `style.css` — estilos personalizados.
- `script.js` — toda a lógica do aplicativo.
- `.nojekyll` — avisa o GitHub Pages para publicar os arquivos como estão.

## Como publicar no GitHub Pages
1. Crie um repositório **público** (nome sem espaços nem acentos).
2. Envie os arquivos para a **raiz** do repositório (soltos, sem pasta).
3. Em *Settings → Pages*, escolha *Deploy from a branch → main → /(root)* e salve.
4. Aguarde alguns minutos: o link aparece no topo da página de Pages.

## Observações
- O app precisa de internet para carregar o Tailwind, as fontes e a IA.
- Os dados ficam salvos apenas no navegador do usuário (localStorage).
- A chave de API (opcional) é digitada pelo usuário e **não** fica no código.
